Preguntas del laboratorio

¿Por qué es buena práctica validar inputs con JavaScript antes de enviar al servidor?
Mejora la experiencia del usuario, ya que JavaScript puede revisar errores antes de mandar todo al servidor, de manera que el usuario recibe el error al instante y no tiene que esperar a que cargue otra vez la página.


¿Cómo puedes saltarte validaciones hechas solo con JavaScript?
Desactivando JS en el navegador, o también editando el código desde las herramientas del desarrollador. La validación con JavaScript es buena como primer filtro, pero la validación realmente importante siempre debe hacerse también en el servidor.
